# Colorama простыми словами

Colorama помогает менять цвет текста в терминале. Эта программа показывает, как ею пользоваться и какие команды в ней есть.

## Установка и запуск

Откройте в VS Code меню **Terminal -> New Terminal**. Команды вводите в открывшийся терминал, а не в файл с кодом.

### Windows PowerShell

Перейдите в папку, где лежит файл задания. Например, если файл находится в `Downloads`:

```powershell
cd $HOME\Downloads
```

Установите Colorama и запустите файл:

```powershell
py -m pip install colorama
py .\colorama_introspection.py
```

Используйте один и тот же способ запуска Python для установки и запуска программы. Если программа сама показывает команду установки, скопируйте именно её: в ней указан нужный Python.

### Linux и macOS

В папке проекта выполните:

```bash
python3 -m pip install colorama
./colorama_introspection.py
```

Установить Colorama достаточно один раз. Если запустить программу без библиотеки, она покажет подходящую для текущей системы команду установки.

## Что делает программа

1. Включает Colorama и задаёт настройки. Например, `autoreset=True` возвращает обычный цвет после каждого сообщения.
2. Показывает несколько примеров: цветной текст, цветной фон и яркий текст.
3. Предлагает ввести свою фразу и показывает её зелёным цветом. Подсказка подскажет, какой командой задаётся цвет.
4. Печатает названия доступных цветов и команд, а также основные команды Colorama.

## Самые нужные команды

- `Fore` меняет цвет букв. Например, `Fore.GREEN` делает текст зелёным.
- `Back` меняет цвет фона.
- `Style` меняет стиль текста или возвращает обычный вид.
- `Cursor` содержит команды для перемещения курсора.
- `init()` включает Colorama, а `deinit()` завершает её работу и восстанавливает обычный вывод.

## Как сделать так же в своей программе

Создайте файл `hello.py` и вставьте в него этот код:

```python
from colorama import Fore, init

init(autoreset=True)
print(Fore.GREEN + "Hello my neighbour")
```

Сохраните файл сочетанием **Ctrl+S** рядом с программой. После упражнения она покажет готовую команду запуска для вашей системы и того же Python. Скопируйте команду целиком в терминал. Не вводите путь к файлу отдельно: Python должен запускать файл.
