# Интроспекция Colorama

Небольшое исследование библиотеки [Colorama](https://pypi.org/project/colorama/): задаются параметры инициализации, демонстрируется цветной вывод и с помощью `inspect` изучаются важные атрибуты и функции.

## Запуск

```bash
python3 -m pip install colorama
python3 colorama_introspection.py
```

В примере вызывается `colorama.init(autoreset=True, convert=None, strip=None, wrap=True)`. `autoreset=True` сбрасывает стиль после каждого вывода, а `None` для `convert` и `strip` позволяет Colorama выбрать поведение с учётом среды. `wrap=True` оставляет обёртку потока вывода включённой.

## Что важно в API

- `Fore`, `Back` и `Style` содержат строковые ANSI-коды для цвета текста, фона и начертания. Это атрибуты-константы, а не функции; например, `Fore.RED` и `Style.BRIGHT` можно объединять с обычными строками.
- `Cursor` предоставляет управляющие последовательности для перемещения курсора.
- `init()` настраивает преобразование ANSI-последовательностей и сброс стилей. `deinit()` снимает установленные обёртки потоков, а `reinit()` восстанавливает ранее созданные обёртки.
- `just_fix_windows_console()` — отдельная простая функция для поддержки ANSI в Windows; она полезна, когда не нужны параметры `init()`.
- `AnsiToWin32` — низкоуровневая обёртка потока. Для обычного форматирования текста удобнее публичные `Fore`, `Back` и `Style`.

Скрипт выводит реальные сигнатуры установленной версии Colorama, поэтому детали интроспекции можно сверить с локальной версией пакета.
